# Fraud: справка по объектам

Здесь описаны данные и методы сервиса. Нужные изменения для ЛР2 перечислены в [TASK.md](TASK.md).
Часть методов уже реализована в заготовке, остальные добавляются по мере выполнения работ.

## Данные и поведение

Сервис риска складывает баллы за признаки операции. Шкала условная и используется только в учебном проекте.

`FraudCheckContext(amount: Money, merchant_category, recent_count)` содержит положительную сумму в EUR, категорию магазина и число предыдущих попыток. `recent_count` — целое неотрицательное число без текущей попытки. История и временное окно уже подготовлены вызывающим кодом.

`FraudResult(score, triggered_rules)` хранит целый балл от `0` до `100` и `tuple` уникальных кодов в порядке правил. Свойство `decision` вычисляется: при `score >= 60` — `DECLINE`, иначе — `ALLOW`.

Общий интерфейс — `FraudRule.evaluate(context) -> int` и свойство `code: str`. Каждое правило возвращает целое число от `0` до `100`; ноль означает, что признак не сработал. Начальные реализации — `LargeAmountRule` и `HighRiskMerchantRule`.

`FraudService.check(context)` вызывает все правила, складывает их баллы и ограничивает итог значением `100`. Коды всех положительных вкладов сохраняются даже после достижения этого максимума. Готовая проверка отклоняет неверный вклад с `INVALID_RULE_RESULT`.

## Работа с готовым кодом

Обращение к сервису выполняется через `app/api.py`. Разрешённые файлы указаны в [TASK.md](TASK.md).
Проверки используют подготовленные данные и не зависят от работы других групп.

Функции `create`, `make`, `call` и `view` связывают готовый API с реализацией. Используемые ими функции сервисного модуля должны сохранять сигнатуры. Сам `app/api.py` не редактируйте.

До ЛР5 сборка предоставлена готовой. Нужные объекты могут создаваться в сервисном модуле; `assembly.py` менять не нужно.

## Ошибки и результаты

`DomainError` содержит код ошибки. При отказе проверки состояние объекта не должно меняться.
Ошибка переданной зависимости не заменяется успешным результатом. Конкретные коды и примеры
приведены в задании и открытых тестах.
